# ROSPacer 1.0 — 2026-10-15

Git tag: `v1.0`. Python package version: `1.0.0`.

W1 구현과 W2 3회 반복 배치가 끝난 뒤 추가 최적화 전에 보존한 연구 버전입니다.
상세 사용법과 검증 범위는 루트 README를 기준으로 합니다.

## 기존 GitHub 버전과의 관계

백업 직전 원격 `main`은 `56f872dd9a38196b2e4ab8860014e9532a3b2206`이었습니다.
이는 다른 프로젝트가 아니라 현재 구현의 조상이며 로컬에 후속 커밋 37개가 있었습니다.
이력을 유지하고 `pre-v1.0-20261015` 태그로 이전 원격 상태를 보존합니다.
따라서 기존 파일을 별개 구현인 것처럼 `past/version0`로 이동하지 않습니다.

기존 원격 버전 대비 추가·보강한 내용:

- 실제 DDS 런타임 고정, 교정·역압·단편·큐·무선 관측·시계 검증 도구.
- 송신 측 `sender-calibrate`, `sender-validate`, `sender-govern` 통합.
- 초기 수신 PHY 교정과 실행 중 송신 측만 관측하는 제한된 운용 모델.
- Receiver-assisted, monitor 기반 관측, ACKNACK 후보의 코드·실패 조건 보존.
- W2 자동 매트릭스, 경쟁 단계별 독립 포트·일정, T3 공통 시작 배리어.
- 케이스 실패 격리, 환경 미복구 시 보호 중단, 유한 준비·종료 복원.
- 전체 결과 보고서와 byte-exact 집계 근거·소스 스냅샷·검증 도구.
