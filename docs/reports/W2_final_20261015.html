처리량·전달률·p99·지터·회복의 정의
C₀와 ρ
C₀는 교정한 UDP 응용 데이터 처리량이며 PHY 속도 자체가 아닙니다. ρ는 교정 용량 대비 요청 응용 부하의 비율입니다. T1 요청 발행률은 r = ρC₀ / (8 × 1 MiB). T3는 두 수신 복사와 송신자별 교정을 반영합니다.
측정창 처리량
T1은 실제 측정 시작부터 정해진60/80초 동안 도착한 고유 메시지 수 × 1 MiB ×8 ÷ 측정시간입니다. warmup·drain 도착을 이 분자에 넣지 않습니다. 전체 수신 수는 drain을 포함합니다.
발행 대비 / 요청 대비 수신율
발행 대비는 고유 수신/성공한 publish() 수, 요청 대비는 고유 수신/원래 목표 생성 수입니다. 역압으로 발행량이 감소하면 전자는100%여도 후자는 낮을 수 있습니다. T3는 목표 복사 수를 두 배로 둡니다.
종단 지연과 지터
지연은 publish() 직전 시각부터 수신 콜백까지이며 직렬화·큐 대기를 포함합니다. 시계 오차 상한1 ms 이하만 계산합니다. 지터는 |연속 고유 도착 간격−요청 발행 주기|의 p99로 생성 지연·역압·미수신 영향도 포함합니다. 무선만의 지터나 지연의 표준편차가 아닙니다.
p99의 집계
run별 p99를 계산하고 그 세 값의 중앙값을 표시합니다. 세 run 전체 표본의 통합 p99가 아닙니다. 표 범위는 세 run의 최소–최대입니다.
미회복과 미수신
관측창에서 회복 임계값을 달성하지 못한 것은 관측 종료까지 미회복(중도절단)입니다. 0초로 채우거나 회복한 run만으로 전체 평균을 내지 않습니다. 관측 종료까지 미수신을 곧바로 영구 패킷 손실로 단정하지 않습니다.
정적 설정·큐·배출 대기의 해석
